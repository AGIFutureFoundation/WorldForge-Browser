# RP1 scene installers: the SmartCiti.X Holodeck

These are ready-to-install scenes that put the SmartCiti.X Holodeck into an RP1 / Metaversal spatial fabric (MSF map
service). They were generated by `tools/rp1_export.py` in the SmartCiti.X worlds monorepo and are committed here as
built output.

| Folder | Scene | Objects / models |
|---|---|---|
| [`smartciti-holodeck/`](smartciti-holodeck/) | The whole Holodeck: simulator yard plus robotics wing | 227 / 170 |
| [`holodeck-simulator-yard/`](holodeck-simulator-yard/) | Only the simulator yard (`holodeck-sims`) | 12 / 12 |
| [`holodeck-robotics-wing/`](holodeck-robotics-wing/) | Only the robotics wing (`holodeck-robotics`) | 96 / 46 |

**Install either the whole scene or its two parts, never both.** The parts are pieces of the whole scene, so
installing both would place the same buildings twice.

## Install (each folder)

1. Copy `objects/*.glb` into `MSF_Map_Svc/dist/web/objects/`.
2. Copy `install_scene.js` into `MSF_Map_Svc/dist/` (beside `settings.json`).
3. Dry run: `DRY=1 node install_scene.js`. Real run: `node install_scene.js`.
4. Open Scene Assembler on the map service, check the scene, and Publish. It shows the Spatial Fabric URL.
5. In the RP1 Dev Center, attach that URL to Earth at the Holodeck's anchor.

## Status

These scenes have **not yet been tested against a live map service**. Check one object's placement before
installing a large scene. No credentials are read or stored here: the installer uses the map service's own
`settings.json`.
