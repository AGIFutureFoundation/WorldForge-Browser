# RP1 scene installer: smartciti-holodeck-robotics

Generated by `tools/rp1_export.py` from `my-fabric/holodeck-robotics.json`: 96 objects, 46 models.

1. Copy `objects/*.glb` into `MSF_Map_Svc/dist/web/objects/`.
2. Copy `install_scene.js` into `MSF_Map_Svc/dist/` (beside `settings.json`).
3. Dry run: `DRY=1 node install_scene.js`. Real run: `node install_scene.js`.
4. Open Scene Assembler on the map service, check the scene, and Publish. It shows the Spatial Fabric URL.
5. In the RP1 Dev Center, attach that URL to Earth at this world's coordinates (see `anchors.json`).

Not yet tested against a live map service; check one object's placement before installing large scenes.
