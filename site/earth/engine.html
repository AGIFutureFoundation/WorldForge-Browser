WorldForge Engine

The entry engine for rp1.com — a replacement for Artemis as the way in. WorldForge turns any real-Earth place into an rp1.com space and serves the 3-D payload behind each enter link: 544 registered worlds, 41 with full Sneeze engine payloads, open enter links for any coordinates. How others use the engine

One link. Drop it in any page, app or QR code — the engine turns the coordinates into an rp1.com entry:

<a href="https://worldforge-api.fly.dev/v2/rp1/enter?lat=40.7055&lon=-74.0135&go=1">Enter this place in RP1</a>

Or resolve the link first (JSON), for any place on Earth:

GET https://worldforge-api.fly.dev/v2/rp1/enter?lat=51.4967&lon=0.0367
<- { "engine": "WorldForge", "enterUrl": "https://enter.rp1.com?start_cid=553&lat=51.4967&lon=0.0367&rad=6371000" }

API

RouteWhat it does
GET /v2/engineengine manifest: identity, conventions, world counts
GET /v2/rp1/enter?lat=&lon=&rad=[&go=1]any real-Earth place → an rp1.com enter link (go=1 opens it)
GET /v2/rp1/enter/:slug?go=1enter link for a registered WorldForge world (go=1 opens it)
GET /v2/rp1/worlds · /v2/rp1/worlds/:slugthe 544-world registry (place, coordinates, enter link, mount status)
GET /v2/rp1/connectionsevery RP1 space connected to its Fly.io-hosted world
GET /v2/sneeze/plans[/:slug] · /v2/worlds/:slug/preview.glbthe Sneeze 3-D payload (mount plans, shared assets, preview GLBs)
