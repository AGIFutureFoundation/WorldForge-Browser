The problem

A spec is not a scene

Worlds exist on paper

41 worlds are specified, with zones, agents and citations in my-fabric/worlds/index.json. A host engine cannot load a specification.

Objects need owners

In a shared world every object needs an owner, a bounded region and a permission matrix that a native loader can read without trusting display names.

Agents must not hold power

Agents will run these worlds. Final votes, the charter, the treasury, enactment, windfall and appointments must be rights no agent can ever hold.

source: my-fabric/worlds/index.json, worldforge/README.md

What we built

SmartCiti.X Master Cards, Volum and permissions

939 cards across 41 worlds: 41 world, 41 plaza, 41 gate, 41 council, 123 seat, 41 omega, 41 coordinator, 123 advisor, 205 zone, 242 agent.

Each card carries an owner (AGI Future Foundation PBC), a Volum (a box: centre and half-extents in metres, Y up) and a permission matrix over view, enter, build, operate, delegate, transfer, govern. Every node in each world's GLB carries its cardId in extras, so a loader indexes cards without display names.
